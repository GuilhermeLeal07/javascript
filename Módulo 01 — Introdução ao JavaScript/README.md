# Módulo 01 — Introdução ao JavaScript

Este módulo reúne os primeiros estudos e práticas de **JavaScript**, apresentando os conceitos iniciais de integração da linguagem com documentos HTML.

O objetivo desta etapa é compreender como o JavaScript pode ser incorporado a uma página web, explorando diferentes formas de execução de scripts e a utilização do console do navegador para exibir mensagens.

---

## 📖 Sobre o módulo

Neste primeiro módulo, são apresentados os conceitos introdutórios da utilização de JavaScript no desenvolvimento web.

Os exercícios demonstram como adicionar códigos JavaScript diretamente em um documento HTML ou por meio de arquivos externos, permitindo separar a estrutura da página da lógica de programação.

Também é explorada a utilização do `console.log()` para exibir mensagens no console do navegador e acompanhar a execução dos scripts.

---

## 📚 Conteúdos abordados

- Introdução ao JavaScript;
- Integração entre HTML e JavaScript;
- Utilização da tag `<script>`;
- Inclusão de JavaScript diretamente no HTML;
- Importação de arquivos JavaScript externos;
- Utilização do `console.log()`;
- Execução de scripts no navegador.

## 💻 Práticas desenvolvidas

### 01. Integração do JavaScript com HTML

Utilização da tag `<script>` para incorporar códigos JavaScript diretamente no documento HTML e importar um arquivo externo.

### 02. Execução de scripts

Experimentação da execução de instruções JavaScript por meio de diferentes formas de inclusão no HTML.

### 03. Utilização do console

Aplicação do método `console.log()` para exibir mensagens no console do navegador.

---

## 🎯 Objetivos de aprendizagem

- Compreender a função do JavaScript no desenvolvimento web.
- Identificar como integrar JavaScript e HTML.
- Conhecer as formas de inclusão de scripts em documentos HTML.
- Separar códigos JavaScript em arquivos externos.
- Utilizar o console do navegador para visualizar mensagens durante a execução dos scripts.
