# JavaScript

Este repositório reúne meus estudos e práticas de **JavaScript** durante minha formação em Desenvolvimento Web.

O objetivo é construir uma base sólida em programação e desenvolvimento Front-end, documentando minha evolução por meio de **exercícios, aplicações práticas e estudos**, organizados de forma progressiva e padronizada.

Os conteúdos acompanham cada etapa dos estudos, preservando a proposta original dos exercícios e aplicando boas práticas de organização, legibilidade, documentação e versionamento.

---

## 📖 Sobre o repositório

Este repositório registra minha evolução em **JavaScript**, desde os primeiros conceitos da linguagem até recursos modernos, manipulação de páginas web e comunicação com APIs.

Os estudos estão organizados em módulos, permitindo acompanhar os conhecimentos adquiridos ao longo da formação. Cada etapa aborda conceitos fundamentais da programação e sua aplicação prática, contribuindo para o desenvolvimento da lógica de programação e da capacidade de construir aplicações interativas e dinâmicas.

Durante a organização e o desenvolvimento dos exercícios, procuro aprimorar aspectos como:

- Lógica de programação;
- Declaração e manipulação de variáveis;
- Operadores e estruturas de controle;
- Organização e reutilização de funções;
- Manipulação de arrays e objetos;
- Programação Orientada a Objetos;
- Depuração e identificação de erros;
- Programação assíncrona;
- Manipulação do DOM;
- Interatividade por meio de eventos;
- Utilização de recursos modernos do JavaScript;
- Consumo e integração com APIs;
- Organização e legibilidade do código;
- Documentação;
- Versionamento com Git e GitHub.

As melhorias realizadas buscam **preservar a proposta original de cada exercício**, sem descaracterizar o conteúdo estudado.

## 📈 Evolução dos estudos

O repositório acompanha minha evolução em JavaScript, registrando os conceitos aprendidos e sua aplicação prática ao longo da formação.

A primeira etapa é dedicada à construção de uma base sólida na linguagem, passando por lógica de programação, estruturas de controle, funções, arrays, objetos e Orientação a Objetos.

Com o avanço dos estudos, os conteúdos passam a explorar recursos mais específicos do desenvolvimento web, como programação assíncrona, manipulação do DOM, eventos, recursos modernos do JavaScript e integração com APIs.

Essa evolução busca transformar o conhecimento teórico em habilidades práticas, desenvolvendo progressivamente a capacidade de criar aplicações web interativas e funcionais.
